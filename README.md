# 工作计划表与简报梳理（workbuddy-work-diary）

你是否被每周填工作计划所困扰——填多了想不起来干了啥还烦，填少了完全体现不出干了多少工作！这套工具让 AI 替你解决：它会在电脑后台安静自动采集，定时截图、记录你打开的文件与产出，全程不打扰你操作，悄悄攒下你一整天的工作素材；每天自动生成当日工作简报，每周汇总整理成可直接复制的周工作计划清单，不用你手动记流水，工作复盘、整理台账直接拿结果。

> 让 AI 帮你把「今天干了什么」自动变成工作总结和每周工作计划表——你只管干活，素材它攒，总结它写，你只看结果。

## 这是什么

一套已在生产环境验证数月的**无感工作采样与总结体系**：

| 层 | 做什么 | 产出 |
|---|--------|------|
| 采集层 | 定时截屏 + 最近文件痕迹 + AI 助手生成内容留档（后台只读，你毫无感知） | `monitor/logs/` 按日采样日志、`monitor/screenshots/` 截图 |
| 素材层 | AI 生成内容、沟通风格沉淀进语料库 | `monitor/corpus/` 各渠道语料 |
| 总结层 | 每天 16 点出当日报告；周一额外把上周一到今天压缩成 ≤20 字/条的工作清单 | `monitor/reports/YYYY-MM-DD-总结.md`、`工作计划表素材-YYYY-MM-DD.md` |

解决了什么痛点：

- 写日报/周报/工作计划表时想不起来自己干了什么
- 用的 AI 助手生成了很多好内容，但没沉淀、下次重新来
- 重复劳动自己都忘了自己在重复，永远变不成自动化

## 核心设计原则

1. **无感**：采集全程后台只读，不打断、不提问、不需要你配合
2. **有据**：报告里每条结论都有截图/文件记录出处；采不到的时段如实写「数据缺口」，按痕迹补的段落强制标注，绝不编造
3. **质检闭环**：每天抽查截图核对日志；漏采、标记失效、任务漏跑都能被第二天发现
4. **沉淀有门槛**：新自动化必须「方案清晰 + 频次明确 + 可无人值守」三条同时满足，先查重、先试跑、再转周期；语料满 20 条才提议蒸馏风格 skill，且必须你确认

## 一键部署（3 步）

依赖：一个支持定时自动化 + 截屏能力的 AI 助手运行环境（WorkBuddy 开箱即用，其他平台见 `docs/porting-guide.md`）。

```bash
git clone <本仓库> workbuddy-work-diary
cd workbuddy-work-diary
python install.py --target /你的/工作目录
```

脚本会创建 `monitor/` 目录结构、部署纯净模板（全部虚构示例，看懂格式后可删）并自检。然后按脚本输出的提示：

1. **装 skill**：把 `skill/work-diary/` 复制到 `~/.workbuddy/skills/`（或导入你的助手的技能体系）
2. **注册采样自动化**：prompt 复制自 `prompts/automation-sampling.md`，工作日整点
3. **注册总结自动化**：prompt 复制自 `prompts/automation-daily-summary.md`，每天 16:00（周一自动追加工作计划表素材）

## 每天的体验

- 平时：什么都不用做
- 每天 16:00 左右：收到 5–8 行汇报——今天主线、AI 助手内容概况、可疑时间浪费点、新建了哪些自动化、语料条数、报告路径
- 每周一：额外收到 `工作计划表素材-YYYY-MM-DD.md`，每条不超过 20 字，直接粘进你的工作计划表
- 想细看：打开当日报告，时间线精确到分钟、每个文件名都有出处

## 常见问题

**Q：会被采集到隐私吗？**
采集只落在本机 `monitor/` 目录，不上传。报告只写「做了什么」，不复制敏感内容。语料只记录你自己发起/确认过的 AI 生成内容。

**Q：采样任务挂了怎么办？**
总结任务会自动发现「整点空档」并写入数据缺口；连续多日异常会明确提示排查。Recent 文件痕迹是兜底证据源，即使没截图也能还原大致时间线。

**Q：如何把重复劳动变成自动化？**
总结任务每天在「可自动化清单」里按 值得做/观望/不建议 三档记录；只有「值得做」且方案清晰、频次明确、可无人值守的才会被创建，创建后先试跑核对再转周期。不满足条件的永远留在观望档等你确认。

**Q：可以用它写给别人看的工作总结吗？**
可以，这正是主要用途。报告结构（结论/时间线/产出物/归类/缺口）就是按「直接抄进日报周报」设计的，周一素材每条 ≤20 字可直接粘表格。
