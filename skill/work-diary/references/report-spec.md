# 报告与素材写作规范

## 每日总结报告（monitor/reports/YYYY-MM-DD-总结.md）

固定结构，按此顺序输出：

```
# YYYY-MM-DD 工作总结

## 一句话结论
今天主要在做哪几件事，2–3 句内说完。若有异常（漏采、误判、链路中断）在此先行声明。

## 时间线
按时段列出做了什么，每条含：时刻 + 程序/应用 + 涉及文件名。
无采样的时段可用 Recent 痕迹补齐，但必须标注「未采到画面，按 Recent 痕迹」。

## 产出物清单
今天新建或修改的重要文件（含报告与素材本身）。

## 灵犀/AI 助手使用情况
今天用了几次、生成了什么类型的内容、质量如何。
语料文件当天有新增时挑代表性段落点评。
口径：按「会话」计次不按留档条数计，AI 助手面板自身输出不计入。

## 工作主题归类
按用户实际工作域定制标签（如：合同审查 / 文书起草 / 台账统计 / 沟通协调 / 其他 / 工具建设）。

## 可自动化清单
- 值得做：方案清晰 + 频次明确 + 可无人值守，才进入派生流程
- 观望：有价值但方案不清楚或依赖用户确认
- 不建议：如触发目标系统防护机制、强人工绑定、一次性动作

## 数据缺口
哪些时段没采到样、为什么、影响什么结论。如实写，宁多勿漏。
```

写作纪律：
- 语言用简体中文（与用户一致），先结论后过程
- 不堆小标题套话，不用 emoji
- 每条结论须有出处（日志、截图、Recent、语料）；无出处的不写
- 截图抽查发现描述不符时，在报告里更正并注明「无需更正日志」或已修正

## 周一素材（monitor/reports/工作计划表素材-YYYY-MM-DD.md）

```
# 工作计划表素材（YYYY-MM-DD）

按日分档，每条不超过 20 字；周末不列；无佐证的不编造；自动化产出已标注。

## MM-DD 周X
- 条目1
- 条目2
...

---
覆盖日期范围：…。周末不列。缺采样日期按「未证实」标注并说明原因。
```

条目写法：
- 动词开头，结果导向：「起草2027年度法治合规管理报告V1」
- 已有自动化执行的事项末尾标「（自动化）」
- 周一当天的工作只统计到执行时刻为止，采到什么写什么

## 日志格式（采样层，供核对用）

```
# YYYY-MM-DD 操作采样日志

## HH:MM
- 截图：screenshots/YYYY-MM-DD/HH-MM.png（分辨率，大小）
- 截图内容：前台应用与窗口、正在进行的操作、背景关键元素
- 活动痕迹：Recent 最新文件、下载目录新增
- 摘要：一句话概括
- 灵犀：有无生成内容、corpus 是否追加
- 沟通渠道（按用户实际使用命名，如企业 IM/邮件）：有无聊天窗口
- 可自动化点：观察到的重复劳动
```

日志末尾状态标记：`<!-- 状态：未总结 -->` → 总结后改 `<!-- 状态：已总结 YYYY-MM-DD HH:MM -->`。标记机制失效时按「当日日志即待总结批次」兜底，并在报告数据缺口提示。
